### Key Features

- User registration and login
- Product browsing and product details
- Shopping cart and wishlist
- Checkout and order management
- User profile management
- Administrative product and user management
- Sales information and database integration

### Project Technologies

Java, JSP, Servlets, MySQL, Maven, HTML, CSS, and Apache Tomcat.

For project-specific instructions, configuration, and database setup, refer to the README inside the `Project (ShopSphere)` folder.

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/nehamulanihub/Java-Practicals-and-Project.git
```

### 2. Open the Project Folder

```bash
cd Java-Practicals-and-Project
```

### 3. Explore the Practicals

Open any practical folder and review its source code. Follow the instructions or dependencies provided within the individual folder, if applicable.

### 4. Run Java Programs

Install a compatible Java Development Kit (JDK), then compile and run standalone Java programs using:

```bash
javac FileName.java
java FileName
```

Replace `FileName` with the actual Java class name. Some programs may require additional setup or different execution instructions.

### 5. Run ShopSphere

ShopSphere requires the appropriate Java JDK, Maven, MySQL, and Apache Tomcat setup. Follow the detailed setup instructions in its project folder.
