# Java RMI Calculator

## 📌 Description

This project is a **Basic Calculator using Java RMI**.
The client remotely calls calculator methods such as **Addition, Subtraction, Multiplication, and Division** from the server.

## 🛠️ Technologies

* Java
* Java RMI
* RMI Registry

## 📂 Files

```text id="z8q1vn"
Calculator.java
CalculatorImpl.java
Server.java
Client.java
```

## ▶️ How to Run

Compile:

```bash
javac *.java
```

Start RMI Registry:

```bash
start rmiregistry
```

Run Server:

```bash
java CalculatorServer
```

Run Client:

```bash
java CalculatorClient
```

## 🎯 Purpose

To perform basic arithmetic operations using **Java RMI** and understand remote method invocation.
