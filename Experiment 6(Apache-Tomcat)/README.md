# Apache Tomcat & Basic Web Application

## Aim
To install and configure Apache Tomcat and create and run a simple web application using an HTML page.

## Technologies Used
- HTML
- Apache Tomcat 11
- Web Browser

## Project Structure
```text
MyWebApp/
└── index.html
```

## Procedure
1. Install and configure Apache Tomcat.
2. Create a folder named `MyWebApp` inside the `webapps` directory.
3. Create an `index.html` file inside `MyWebApp`.
4. Start the Tomcat server.
5. Open the application in a web browser.

## Application URL
```text
http://localhost:8080/MyWebApp/
```

## Output
The web page displays a welcome message.

## Result
A basic web application was successfully created and executed using Apache Tomcat.
